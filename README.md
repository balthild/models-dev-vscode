# models-dev-vscode

Add Copilot BYOK models with information fetched from [models.dev](https://models.dev). The id, name, API url, API format, context window, max output, reasoning efforts, and capabilities of each model will be set automatically.

## Installation

[VS Marketplace](https://marketplace.visualstudio.com/items?itemName=balthild.models-dev-vscode)

## Usage

Click “Add Models” in language models settings page and choose “Models.dev”, or run “Models.dev: Add Provider” from command palette.
